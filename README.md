# Vehículo Análisis Web App

## Descripción

Esta aplicación web permite visualizar y analizar un conjunto de datos sobre anuncios de ventas de vehículos. A través de esta herramienta, los usuarios pueden explorar la distribución de ciertos atributos de los vehículos y obtener información visual sobre las tendencias en los datos.

## Funcionalidad

La aplicación proporciona las siguientes funcionalidades:

- **Histograma**: Al seleccionar esta opción, el usuario puede visualizar un histograma de dos características clave: la **cantidad de vehículos** y el **odómetro** de los vehículos. Esto ayuda a entender la distribución de estos atributos en el conjunto de datos.
  
- **Diagrama de Dispersión**: Al seleccionar esta opción, se genera un gráfico de dispersión que muestra la relación entre el **precio** de los vehículos y su **año de fabricación**. Este gráfico permite identificar tendencias y patrones en los precios según la antigüedad de los vehículos.
